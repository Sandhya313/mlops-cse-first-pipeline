Step-1: Create virtual environment
python -m venv kiet-cse

Step-2: Activate virtual environment
In mac:
source kiet-cse/bin/activate

In windows:
kiet-cse\Scripts\activate

Step-3: Create project strcuture
mkdir mlops-first-pipeline
cd mlops-first-pipeline

Step-4: Install required packages
pip install -r requirements.txt

Phase-2: Dockerize ML Application
====================================

Traditional ML Flow:
Dataset -> Train -> Model Evaluation -> Prediction

Production Ready ML Application
Saved Model -> Python App -> REST API -> Automated Test -> Docker Container -> CI/CD
Can be tested, deployed, accessed by clients and maintained consistently


Why we need Docker ?
- Imagine right now ML application is working on your macbook, but fails on another engineer laptop that runs it on a Linux/windows server

Possible reasons of failure:
- Different Python Versions
- Different versions of scikit-learn or FastAPI
- Missing Python Packages
- Different OS dependencies

Docker helps package your application code, runtime, dependencies and startup instructions into a standardized image

4 major requirements:
- Dockerfile - Instructions for packaging the ML application
- Image - packaged reusable application artifact
- Container - Running instance of that image
- Port mapping - Makes the API inside the container accessible from your system

Commands for Docker
1. docker ps = print all running containers
2. docker ps -a = print all active/non-active containers
3. docker build -t cse-mlops 
 = build docker image
 -t = tag = name of the image
 4. docker images = List locally available docker images
 5. start the container
 docker
